# Other downloads from HAGR

This folder contains additional resources downloaded from the Human Ageing Genomic Resources (HAGR). They are retained as shared source material but were not inputs to the completed GenAge Figures 1–6.

## Contents

| Path | Resource | What it contains |
|---|---|---|
| `ARCT-0.9/` | ARCT 0.9 | Perl source code, examples, and build files for the Ageing Research Computational Tools package |
| `cellAge/` | CellAge Build 3 | `cellage3.tsv` with curated cellular-senescence genes and its April 2023 release notes |
| `cellSignatures/` | CellAge expression signature | `signatures1.csv` with cellular-senescence expression-signature data and its release notes |
| `dataset (1)_DrugAge/` | DrugAge Build 5 | `drugage.csv` with 3,406 experimental entries covering 1,045 drugs and its November 2024 release notes |
| `dataset (2)_AnAge/` | AnAge Build 15 | `anage_data.txt` with 4,671 animal ageing and longevity entries and its July 2023 release notes |
| `dataset_GenDR/` | GenDR Build 4 | `gendr_manipulations.csv` with dietary-restriction-related genetic manipulation data and its June 2017 release notes |
| `longevity_genes/` | LongevityMap Build 3 | `longevity.csv` with human longevity association, population, variant, and gene data and its June 2017 release notes |
| `DR gene expression signature.xls` | GenDR expression signature | Downloaded dietary-restriction gene-expression signature spreadsheet |
| `ddw307.pdf` | Supporting literature | Downloaded PDF retained with the HAGR material; its role should be confirmed before use |

The [Task 1 data inventory](../task/task%201/notes/data_inventory.md) records how these resources were distinguished from the GenAge inputs.

## Modification policy

Treat every downloaded dataset, spreadsheet, PDF, release note, and software file in this folder as immutable.

- Do not edit, rename, move, overwrite, or delete downloaded files.
- Do not run formatting or cleanup tools over this folder.
- Do not save analysis outputs here.
- Inspecting and reading files is allowed.
- Copy the required fields into a task-specific derived dataset when an assignment uses one of these resources, and record the exact source path and release/build.
- Put scripts, notes, figures, intermediate files, and result tables in the relevant numbered task folder.
- Updating this README is allowed; document any newly downloaded HAGR resource before using it.

## Use cautions

- These resources cover different biological questions and are not interchangeable with GenAge.
- Release dates and identifier systems differ between databases; joins require documented mappings.
- HAGR release notes warn that live website statistics may differ from stable downloadable builds.
- Confirm citation and use conditions from the accompanying release notes before publication.
