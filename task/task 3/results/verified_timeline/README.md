# Current exploratory timeline data

Generated by `../../scripts/derive_verified_timeline.py` from the pinned official HAGR-R observation IDs, immutable Build 21 catalogue, and cached LibAge bibliography. See `../../notes/verified_timeline_report.md` for the full method and exclusions.

- `verified_observation_references.csv`: 2,732 mapped observation/reference links.
- `entry_references.csv`: unique entry/reference pairs.
- `earliest_reference_provenance.csv`: all tied earliest dated references per entry.
- `entry_coverage.csv` and `coverage_by_organism.csv`: include the two undated entries in denominators.
- `annual_entry_timeline.csv` and `annual_reference_timeline.csv`: source data for the two draft figures.
- `excluded_dangling_backlinks.csv`: 22 links with confirmed entry-not-found destinations.
- `observations_without_bibliography_reference.csv`: the one displayed observation with an empty reference endpoint.
- `corrected_label_assignments.csv`: ten old label-based gene assignments corrected using authoritative IDs and checked directly.
- `audit.json`: hashes, coverage, checks, and exploratory/final readiness.

These tables support an exploratory description of the available references. They do not establish definitive historical discovery dates. Preserve source snapshots and record any future corrections in the Task 3 changelog.
