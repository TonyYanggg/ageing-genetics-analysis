# Task 1 — Baseline GenAge analysis and preliminary figures

## Request

Inventory the downloaded GenAge data and create preliminary descriptive figures showing:

1. the number of model-organism records by species;
2. longevity-influence classifications across organisms; and
3. reported lifespan-effect directions across organisms.

## Status

Complete. The figures were sent to Pedro on 18 August 2026, and he replied that they looked good. The later cross-species panels are retained here as part of the same baseline descriptive work.

All Figures 1–5 listed below are the current outputs of this descriptive task. They are exploratory review-development figures rather than a submission-final figure set.

## Method and reproduction

The first script validates the raw schema and global record/category totals before producing Figures 1–3. The second produces organism-level count and percentage tables and Figures 4–5, retaining all organisms in tables while plotting the five major organisms.

```text
python "task/task 1/scripts/01_basic_descriptive_figures.py"
python "task/task 1/scripts/02_cross_species_descriptive_figures.py"
```

## Verification

On 17 September 2026, both scripts completed successfully against all 2,205 records. Expected organism totals, global category totals, and within-organism percentages matched.

## Decisions and limitations

- The unit of analysis is a GenAge record, not a deduplicated gene.
- Missing lifespan-effect values are displayed explicitly rather than discarded.
- Minor organisms remain in source tables but are excluded from cross-species plots because they contain only one to three records.
- The CSV lacks observation-level manipulation and reference data, so these figures are descriptive summaries only.
