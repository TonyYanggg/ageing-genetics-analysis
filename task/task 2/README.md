Create a review figure comparing the magnitude of reported lifespan-extending effects between model systems.

## Method and reproduction

The canonical plot includes records from the four plotted organisms whose raw `lifespan effect` is exactly `Increase` and whose lifespan-change magnitude parses as a finite number. Boxes show median and interquartile range; points show all included records; labels identify each organism's unique maximum.

```text
python "task/task 2/scripts/fig6_explore_lifespan_effect_magnitude.py" --final-main-only
python "task/task 2/scripts/verify_fig6_data.py"
```

Running the figure script without a flag regenerates the exploratory tables and previews. `--final-plots-only` regenerates both finalized figure variants.

## Verification

The independent audit reconstructed 830 plotting rows and four maximum-label records directly from the raw CSV. It found no sample-size, row-inclusion, magnitude, maximum-label, or plotting discrepancy. The audit also confirmed that verification did not modify any figure file. See the [verification report](notes/fig6_verification_report.md).

## Decisions and limitations

- *S. pombe* is absent because none of its 61 records has a usable magnitude, not because it lacks GenAge records.
- The source website displays the magnitude field as a percentage, but the downloaded CSV does not document the exact calculation across heterogeneous experiments.
- Extreme values are retained because they are present in the source and independently verified.
- Some older audit-table cells use six-significant-digit formatting. These are display-level rounding differences, not plotting discrepancies.
- No old figure should be treated as current solely because it has a later file timestamp; use the status table above.
